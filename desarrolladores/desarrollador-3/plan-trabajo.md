# Plan de trabajo — Desarrollador 3 (Agente de IA, LLMs, Nebius Token Factory y modelos NVIDIA)

Responsabilidades: contrato del agente, proveedor simulado, integración con Nebius Token Factory y con el modelo NVIDIA elegido, investigación y explicación de evidencias, validación de respuestas, gestión de fallos y herramientas de solo lectura; propiedad de `src/servidor/agente/`, `src/servidor/herramientas/` y `src/contratos/informe-evidencias.schema.ts`.

Este plan es la vista diaria del rol de Desarrollador 3 dentro de [plan-desarrollo.md](../../plan-desarrollo.md) y [checklist-implementacion.md](../../checklist-implementacion.md), que siguen siendo la fuente de verdad sobre pruebas y criterios técnicos exactos. Todos los estados inician en `Pendiente`: no se marcan como completados hasta que exista evidencia verificable, según [definicion-de-terminado.md](../../definicion-de-terminado.md).
